Projects & workflows

Open workflows built around real research problems.

Each project captures a methodological problem I have worked through and packages the solution as an auditable, reusable workflow.

Population genomics

PoLoCo

A reproducible pooled low-coverage workflow for draft genome assembly and allele-frequency analysis from ethanol-preserved small non-model invertebrates. It connects preprocessing, assembly, validation, mapping, coverage, Pool-seq filtering, QC and optional connectivity analysis.

GitHub ↗
Mitogenomics

PoMito

A reproducible 00–13 step workflow for mitochondrial genome recovery, validation, annotation, comparative resource building, phylogenomics, publication figures and reproducibility packaging from paired-end Illumina WGS. It supports pooled and individual data, local/ENA/SRA inputs and SLURM execution.

GitHub ↗
Metagenomics

IxMeta

A Snakemake workflow for whole-tick sequencing that separates the Ixodes ricinus host fraction, profiles microbial signals, assembles non-host reads and evaluates selected candidates with genome-wide evidence rather than classifier hits alone.

GitHub ↗
Ecological statistics

Ecological Modeling in R

A reusable portfolio of ecological modelling examples generalized from forest arthropod eDNA analyses, using synthetic data to demonstrate GLMs, negative-binomial models, GAMs, random forests, SEM, diagnostics and visualization independently of a manuscript dataset.
